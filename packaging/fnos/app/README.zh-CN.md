# NES 游戏厅（飞牛原生应用）

在飞牛应用中心安装后，从桌面图标打开，或访问 `http://NAS-IP:8180/`。
首次安装依赖官方 Node.js v24；前端与服务依赖均包含在 FPK 中，无需拉取 Docker 镜像。

- ROM：文件管理 → 应用文件 → nes-web → roms，文件扩展名为 `.nes`。
- 封面：同目录下的 screen，例如 `contra.nes` 对应 `contra.png`。
- 导入或移除 ROM 后，点击网页主页“重新扫描 ROM”，无需重启。
- 主页提供设置、按键设置、语言设置入口；简体中文可在语言设置中选择。
- USB 手柄接在运行浏览器的电脑上，按一下按钮激活；支持标准十字键和左摇杆。
- 日志位于应用运行数据目录 `var/app.log`。

本包不包含 ROM。请仅导入合法持有的游戏文件。
安装和升级不会复制、修改已有 Docker 版的数据；两者可分别使用 8180 和 8080 端口。
生命周期脚本不删除共享目录中的 ROM 或封面。

其他 NAS 目录：先在飞牛应用中心的应用设置中授权目录，再在“配置”中填写
ROM/封面的绝对路径。留空使用默认共享目录。保存目录配置会重启服务，之后增删 ROM
只需网页“重新扫描 ROM”，无需重启。扫描仅处理目录第一层的 `.nes` 文件。
